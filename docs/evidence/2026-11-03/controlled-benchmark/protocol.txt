Controlled numerical benchmark v1 — fixed before first execution, 3 November 2026.
Purpose: evaluate two explicit design choices with known numerical ground truth, rather than optimizing cache speed or picking good historical frames.
Runtime: existing Geometry Docker image a7217c7, isolated GCP container, no network/credentials/runtime mounts, 1 CPU / 2 GB RAM / 10-minute hard timeout. No production code edits. Preserve exact script and source hashes.
Experiment A: compare raw camera poses (earlier projection choice), unconditional ICP proposal (ablation), and the current actual choose_camera policy. Use actual align_frame and choose_camera from the pinned image. A temporary in-memory wrapper observes the true policy decision while exposing the proposal transform; it does not edit source or services.
Cases: 12 seeded varied three-surface rooms with moderate 4–10cm / 0–1.5degree pose drift and 2mm depth noise; 4 clean-pose controls; 4 larger-drift cases (30cm / 6degrees); 4 single-plane normal-drift cases; 2 single-plane tangential-drift ambiguity controls. Seeds/case construction fixed in benchmark.py. All rows retained, no retuning or best-run selection.
Ground truth: analytic scene and camera transform, independent of initial pose. Metric: translation norm error in mm, rotation geodesic error in degrees, accepted coverage, rate of accepted poses above 10mm or 0.5degrees, elapsed calculation time. Report recoverable-room stratum separately from stress/degenerate cases. Rejected cases have no error value; do not count them as perfect predictions. A single plane cannot reveal tangential camera drift; do not silently remove this limitation.
Experiment B: compare the same actual compare_surfaces function with camera-side selection disabled vs enabled. 18 parallel double-surface wall cases: thickness 0.12/0.20/0.30m crossed with true interior offsets -0.02/-0.06/-0.10/-0.14/-0.18/-0.22m. Ground truth is the observed interior face displacement, not distance to whichever face happens to be nearest. Input geometry and structural labels identical. Metric: signed-offset absolute error in mm and errors exceeding 1mm. This is a designed ambiguity stress test, not prevalence-weighted field accuracy or a complete historical checkout benchmark.
No Meta calls: these tests assess numerical handling downstream of semantic evidence, not SAM mask quality. Synthetic geometry is a controlled numerical ground truth, not real-site validation. Publish all successes, failures, and ambiguity controls. No significance claims across correlated fixtures; no universal optimality claim.
